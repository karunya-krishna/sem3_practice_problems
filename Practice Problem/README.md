## Run
Each week folder contains one standalone Java source file. From that folder:

```bash
javac Week09BasicJava.java
java Week09BasicJava
```

Use the corresponding filename for Weeks 10, 11 and 12.

The `main` method demonstrates representative examples from the PDF. The remaining problem solutions are exposed as static methods or nested classes so they can be tested independently. MCQs and Part C written-response questions are not converted into programs.

Complexity notes are included beside the relevant algorithm implementations.
