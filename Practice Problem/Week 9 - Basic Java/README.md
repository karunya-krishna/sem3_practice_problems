# Week 9 — Basic Java

Solutions for all 10 Part A problems in `CATEGORY-C-DATA-STRUCTURE_PRACTICE.pdf`.

Compile and run: `javac Week09BasicJava.java && java Week09BasicJava`.

Methods cover vowel/consonant counting, StringBuilder reversal and palindrome checking, even/odd counting, in-place reversal, digit sum/reversal, prime checking, factorial, grade assignment, leap-year detection and the Student result card.
