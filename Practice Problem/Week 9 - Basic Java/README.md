# Week 9 — Basic Java

This folder contains the 10 coding problems from the Week 9 Category C PDF.

## Problems
1. Vowel and consonant counter
2. Word reverser and palindrome checker
3. Even and odd numbers in a list
4. In-place array reversal
5. Digit sum and number reversal
6. Prime number checker
7. Factorial calculation
8. Student grade assignment
9. Leap year detector
10. Student result card generator

## Run
Each file is a standalone Java program. From this folder:

```bash
javac 01_VowelConsonantCounter.java
java VowelConsonantCounter
```

Replace the filename and class name for the problem you want to run. Programs that need input read it from standard input; Problem 10 uses the sample student records from the question.

## Main complexity notes
- Character, array and digit scans: O(n) time.
- Prime check: O(√n) time.
- Factorial: O(n) time.
- Student result card: O(1) per student because each student has three marks.

Only Part A coding problems are included. Quiz and concept questions are not separate coding exercises.
