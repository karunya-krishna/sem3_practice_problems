# Week 10 — Data Structures and Algorithms

Solutions for all 10 Part A problems in `CATEGORY-C-DATA-STRUCTURE_PRACTICE_PROBLEMS.pdf`.

Compile and run: `javac Week10DataStructures.java && java Week10DataStructures`.

Includes binary search, grid traversal, HashSet duplicate detection, HashMap lookup, pair-sum search, one-pass stock profit, binary-search insertion position, spiral traversal, two pointers and in-place duplicate removal. Complexity notes are in the source.
