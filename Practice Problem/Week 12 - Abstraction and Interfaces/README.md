# Week 12 — Abstraction and Interfaces

This folder contains all 5 coding problems from the Week 12 Category C PDF.

## Problems
1. Garden plot area report — interface-based shape abstraction
2. Weekly staff pay — abstract class and method overriding
3. Library late fine counter — abstract class and polymorphism
4. Electricity connection billing — abstract class and polymorphism
5. Travel booking with a common fee — shared abstract-class logic

## Run
Each file is a standalone Java program. Example:

```bash
javac 01_GardenPlotAreaReport.java
java GardenPlotAreaReport
```

Use the matching filename and class name for each problem. All five programs read their records from standard input.

## Complexity notes
All five programs process each input record once: O(n) time. Their arrays store one object per record: O(n) space.

Only Part A coding problems are included. Quiz and concept questions are not separate coding exercises.
