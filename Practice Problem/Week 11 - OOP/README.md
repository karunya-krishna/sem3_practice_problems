# Week 11 — OOP and Arrays

This folder contains all 6 coding problems from the Week 11 Category C PDF.

## Problems
1. Campus staff salary — inheritance and runtime polymorphism
2. Class report card — validation, encapsulation and bubble sort
3. Library return desk — array-based stack and circular queue
4. Payment processing — interface and polymorphism
5. Weekly rainfall analysis — arrays and loops
6. Hostel electricity bill — slab calculation and validation

## Run
Each file is a standalone Java program. Example:

```bash
javac 01_CampusStaffSalary.java
java CampusStaffSalary
```

Use the matching filename and class name for each problem. Input-based programs read from standard input.

## Complexity notes
- Staff salary and payment processing: O(n) time for n records.
- Report-card bubble sort: O(n) best case with early stopping; O(n²) worst case.
- Stack and circular-queue operations: O(1) per command.
- Rainfall analysis: O(1) time and space for the fixed seven days.
- Hostel billing: O(n) time for n rooms.

Only Part A coding problems are included. Quiz and concept questions are not separate coding exercises.
