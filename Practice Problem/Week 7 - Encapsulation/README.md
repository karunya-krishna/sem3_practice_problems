# Week 7 — Encapsulation

Contains all 5 coding problems from the Week 7 Category C PDF.

1. Piggy Bank — private balance, controlled deposit/withdraw, final ID
2. Quiz Scorecard — private answer array and score-only access
3. Nickname Tag — immutable name fields
4. Locker Code — write-only combination with current-code validation
5. Attendance Sheet — private name array, duplicate prevention, count and lookup

## Run
Compile and run one problem at a time. For example:

```bash
javac 01_PiggyBank.java
java PiggyBank
```

All programs include a small demonstration in `main`. Each problem is a separate standalone Java file. Only the five coding problems are included; quiz/concept questions are not part of this PDF.
