# Week 8 — Inheritance and Polymorphism

Contains all 5 coding problems from the Week 8 Category C PDF.

1. Payment System Fee Calculation — payment-specific fee behavior
2. Library Item Due Date Calculator — item-specific loan periods
3. Delivery Fee Calculator — delivery-specific pricing rules
4. Examination Question Grader — exact and essay grading behavior
5. Public Transport Fare Calculator — transport-specific fare rules

## Run
Each file is a standalone Java program. Compile and run the required problem:

```bash
javac 01_PaymentSystemFees.java
java PaymentSystemFees
```

The input format follows the PDF. Problem 2 uses the fixed current date 2023-10-26 specified in the question. Problem 4 accepts quoted text fields, as shown in the sample input. All monetary output is formatted to two decimal places.

Only the five coding problems are included; quiz/concept questions are not separate coding programs.
